1. Entendendo os formatos de cor

Associação correta da Coluna B (de cima para baixo):

  1. ( b ) Cor nomeada (Exemplo: blue)
  2. ( a ) Cor hexadecimal (Exemplo: #ff0000)
  3. ( c ) Cor RGB (Exemplo: rgb(255, 255, 0))
  4. ( d ) Cor RGBA (Exemplo: rgba(0, 0, 0, 0.5))
